# Quasaria PolyBot: browser preview (demo data)

This is a static, backend-free preview of a **Quasaria-themed build of Krypt PolyBot** (MIT, (c) Krypt,
https://github.com/kryptccgit/KryPolybot, upstream commit 6f742931a7356f83183c876349b2152c82d32d68).
It uses a mocked in-browser API with synthetic data: no backend, no wallet, no Polymarket connection, no trading.
It is a personal preview, not for resale or rebranding. The upstream MIT LICENSE and DISCLAIMER are included alongside.
